# 社交记忆

## 存储

`fish-memory/shared/social.json`

```json
{
  "version": 1,
  "conversations": {
    "group:123456789": {
      "people": {
        "123456789": {
          "id": "123456789",
          "name": "老大",
          "count": 12,
          "lastSeen": "2026-10-27T12:00:00+08:00",
          "lastText": "今晚早点睡",
          "topics": ["海鲜", "吉他"],
          "commitments": ["今晚十二点前睡"]
        }
      }
    }
  }
}
```

## 隔离

按 `group:...` / `private:...` 分开。

- 群聊不会看到私聊的人
- 私聊不会看到群聊的人

## 注入

每轮最多注入当前会话最近 3 人：

```text
【社交记忆】
- 老大：最近说“……”，常聊：海鲜、吉他
```

## 用途

- 判断谁在说话
- 记住某人的偏好和约定
- 避免把不同人的信息混在一起
