# 自我叙事与元认知

## 自我叙事

从 `kind: episodic` 的长期记忆里取最近 3 条：

```text
【最近的故事】
- 2026/10/27 与用户聊到：……
```

用途：

- 保持“我们之间发生过什么”的连续性
- 不让鱼只记得事实，却忘了经历
- 群聊/私聊按 scope 过滤

## 元认知

长期记忆可以带：

```json
{
  "confidence": 0.5
}
```

注入时：

```text
（这条不太确定）
```

提示词要求：

- 不确定就说记不清
- 不要编造
- 不要把模型推断当成用户事实

## 置信度来源

- 用户明确说的：0.9
- 规则抽取：0.7
- 批量巩固：0.65
- 模型推断：0.5
